# 健保快易通長輩看圖教學

提供門號不是本人時使用「裝置碼認證」的圖解教學。

## 內容

- 首頁優先顯示使用者提供的實機截圖總覽。
- 33 個詳細步驟：19 步實機截圖、14 步動作示意。
- 首次註冊說明戶口名簿戶號、戶籍資料、讀卡與登入。
- 每一步都有觀看位置、操作說明、完成判斷與卡住處理。
- 大字、圖片放大、逐步導覽、朗讀與列印。
- 帳號、QR Code 和文字認證碼已遮蔽。AI 圖片明確標為示意。

## 開啟

下載完整檔案後，用瀏覽器開啟 index.html；assets 資料夾需保持在同一層。
此專案是純 HTML、CSS、JavaScript 靜態網站，不需要安裝套件或編譯。
也可以透過靜態網站主機提供服務。上傳 GitHub 本身不等於啟用 GitHub Pages。

## 檔案

- index.html：實機截圖總覽與逐步教學。
- visual-data.js：步驟內容與紅框位置。
- visual.js / visual.css：互動與版面。
- family.html：完整說明與官方來源。
- assets/：實機截圖與示意插圖。
